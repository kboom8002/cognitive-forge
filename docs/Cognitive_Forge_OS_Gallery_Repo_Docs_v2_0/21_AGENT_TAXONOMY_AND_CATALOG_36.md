# D21 36종 분류·카탈로그

카탈로그 정본은 gallery/catalog/agents36.json이다. 6개 작업군마다 6종을 등록하고 기본 페르소나는 실존 전문가를 사칭하지 않는 역할 묘사로 사용한다. 상품의 핵심은 이름이 아니라 입력·납품물·중대 실패 조건이다.

초기 후보는 AG06·07·08·17·19·20·23·25·26·27·30·35이다. 후보 선정은 출시 완료를 뜻하지 않는다. 기본 예시는 모두 specified·preview_only로 시작한다. 실제 모델 어댑터·평가·권한·실행 E2E를 완료한 릴리스만 runnable로 전환한다. AG17은 텍스트 브리프이며 이미지 생성 능력을 표시하지 않는다. AG30은 제공된 출력 평가를 먼저 제공하고 다른 에이전트 자동 실행은 후속 capability로 둔다.

각 종별 명세는 gallery/agent_specs/에 있다. 폴더의 스키마 예시는 구현팀 전달 계약이며 현재 Forge 런타임이 직접 읽을 수 있다고 가정하지 않는다. 기존 CasePack-MAO 변환 어댑터와 의미 동등성 검사가 필요하다.
