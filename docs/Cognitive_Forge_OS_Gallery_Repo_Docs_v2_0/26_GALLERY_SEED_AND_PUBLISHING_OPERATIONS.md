# D26 기본 등록·전문가 참여 운영

G0 seed는 36종 카탈로그를 preview_only로 등록한다. G1 초기 12종은 시험용 팩으로 가져오되 published로 설정하지 않는다. 모의 출력은 sample_origin=synthetic_fixture로 표시한다. 운영자는 실제 제공자 연결·평가·권한·사용성 증거를 확인해 개별 릴리스를 승격한다.

전문가 참여 흐름은 초대 또는 신청→프로필→기여 역할→자료 권리→특화 팩 작성→시험→갤러리 게시다. 전문직 명칭 확인과 에이전트 품질 평가를 별도로 진행한다. 최초 분야는 기업·소상공인 문서, 교육·지식 서비스, 시각 브리프다. 이미지 생성 팩은 도구·검사 추가 후 별도 출시한다.

운영자의 게시 검토는 제목·소구 문구·공개 자료·능력 표시·권리·실행 상태를 검사한다. 장애 시 신규 실행을 pause하고 기존 run은 운영 정책에 따라 완료·중단 처리한다. 삭제 대신 보관 상태를 사용해 고객 산출물 참조를 보존한다.

갤러리 검색 수, 실행 수, 유료 의뢰는 서로 다른 지표다. 초기 실증에서 제작 시간·수정량·재사용·의뢰 전환을 측정하며 검증되지 않은 성공률을 배지로 표시하지 않는다.
