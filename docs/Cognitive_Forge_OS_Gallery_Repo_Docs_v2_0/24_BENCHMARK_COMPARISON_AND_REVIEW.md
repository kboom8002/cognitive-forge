# D24 공통 과제·비교·피드백

비교는 같은 입력과 납품 유형을 가진 최대 3개 릴리스를 고정하여 수행한다. 품질·시간·비용·질문 수·수정량을 따로 표시한다. 모델과 예산이 다르면 동일 조건 비교라고 표시하지 않고 실제 설정 차이를 보여준다. 다르게 구성된 서비스의 우열을 한 점수로 단정하지 않는다.

BenchmarkTask는 입력, 필수 assertion, 금지 결과, 루브릭, 자료 공개 범위, 버전을 가진다. 평가 결과의 PASS·FAIL·NOT_RUN·ERROR를 보존한다. 같은 과제를 반복 실행해 변동을 관찰하고 대표 사례만 선별하여 평균처럼 광고하지 않는다. 평가 템플릿 작성과 실제 실행을 구분한다.

고객 비공개 자료로 여러 제작자의 서비스를 비교할 때 자료 전달 범위와 보존 조건을 먼저 선택한다. 기본 공통 과제는 합성·공개 자료다. 피드백은 대상 artifact_version과 run_id에 연결한다. 전문가 검토와 사용자 선호는 다른 필드로 기록한다. 검토되지 않은 결과에 검수자 배지를 붙이지 않는다.

AG30 평가자의 판단도 평가 대상이다. 자동 점수는 근거·불일치 사례와 함께 제공하고, 중요 항목은 코드 검사 또는 사람 확인으로 보완한다.
