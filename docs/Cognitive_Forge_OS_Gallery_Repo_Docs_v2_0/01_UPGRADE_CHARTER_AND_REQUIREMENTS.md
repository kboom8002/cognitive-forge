# D01 UPGRADE_CHARTER_AND_REQUIREMENTS

버전 2.0 · 2026-11-01 · 구현 지시 명세

## 목적과 범위
독립 운영을 우선하는 제품 원칙, 사용자·구매자, 포함·제외 범위, R01~R16 요구사항, 출시 단계와 성공 지표를 정의한다. 외부 Work OS 없이도 검수·산출물 관리가 가능해야 한다는 요구를 명시한다.

각 요구사항은 담당 문서, 구현 티켓, 검증 시나리오와 연결한다. 새 요구가 추가되면 영향 범위와 변경 이유를 남긴다.

## 구현 결정
R01 독립 운영을 출시 차단 조건으로 둔다. 제작·시험·발행·실행·검수·내보내기 과정에 타 프로젝트 ID를 필수 입력으로 요구하지 않는다. R02 제작기는 업무 설명과 사례를 받아 초안을 제시한다. 제작 시간, 도움 요청 횟수, 발행 성공률을 관찰하며 아직 측정하지 않은 개선율은 표시하지 않는다. 최초 고객 업무는 기업 소개와 FAQ이며 거래 정산과 범용 자율 코딩은 후속이다.

## 계약 및 검증 연결
공통 객체는 06_CANONICAL_OBJECTS_AND_STATE_CONTRACTS.md, 인터페이스는 13_PUBLIC_API_EVENTS_AND_INTEROPERABILITY.md를 따른다. schemas/, examples/, tickets/, tests/의 동일 식별자를 사용한다. 상태 변경 시 revision을 검사하고 결과 버전을 보존한다.

## 완료 증거
담당자는 변경 파일 목록, 검사 결과 원문, 실패·미실행 항목과 복구 방법을 남긴다. 명세 작성 완료는 소프트웨어 구현 완료를 뜻하지 않는다.
