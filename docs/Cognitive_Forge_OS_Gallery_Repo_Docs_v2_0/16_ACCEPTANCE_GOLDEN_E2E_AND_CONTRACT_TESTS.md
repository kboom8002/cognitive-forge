# D16 ACCEPTANCE_GOLDEN_E2E_AND_CONTRACT_TESTS

버전 2.0 · 2026-11-01 · 구현 지시 명세

## 목적과 범위
독립 운영, 비개발자 제작, 자료 부족, 상충 수치, 실행 오류, 승인, 버전 변경, 테넌트 격리, 보존·삭제, 외부 API와 이벤트의 검증 시나리오를 정의한다.

각 시나리오는 초기 조건, 입력, 사용자·시스템 행동, 기대 상태, 기대 산출물, 확인 근거와 실패 조건을 갖는다. 시뮬레이션·실제 모델·실제 배포 환경 검증을 구분한다.

## 구현 결정
AT01~AT18은 acceptance_cases.json에 초기 조건·행동·기대 결과로 제공한다. 문서·스키마 검증은 로컬 수행하고 실제 UI E2E·실제 모델 평가·DB 격리는 구현 후 실행한다. 프롬프트 변경 시 정상 사례뿐 아니라 자료 부족·상충·악성 자료·권한 거부 사례를 재실행한다. 통과 여부와 원문 로그 위치를 함께 기록한다. 실제 서비스에 연결되지 않은 테스트를 운영 검증으로 표시하지 않는다.

## 계약 및 검증 연결
공통 객체는 06_CANONICAL_OBJECTS_AND_STATE_CONTRACTS.md, 인터페이스는 13_PUBLIC_API_EVENTS_AND_INTEROPERABILITY.md를 따른다. schemas/, examples/, tickets/, tests/의 동일 식별자를 사용한다. 상태 변경 시 revision을 검사하고 결과 버전을 보존한다.

## 완료 증거
담당자는 변경 파일 목록, 검사 결과 원문, 실패·미실행 항목과 복구 방법을 남긴다. 명세 작성 완료는 소프트웨어 구현 완료를 뜻하지 않는다.

## 갤러리 v2 개정 계약
GT01~GT16을 기존 AT와 함께 실행한다. JSON Schema 통과와 도메인 권리·테넌트·실제 모델 검증을 분리한다.
