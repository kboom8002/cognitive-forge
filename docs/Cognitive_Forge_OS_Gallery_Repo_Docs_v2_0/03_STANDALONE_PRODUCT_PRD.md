# D03 STANDALONE_PRODUCT_PRD

버전 2.0 · 2026-11-01 · 구현 지시 명세

## 목적과 범위
제작자, 서비스 이용자, 검수자, 운영자의 작업을 제품 행동으로 정의한다. 핵심 여정은 만들기→시험하기→발행하기→이용하기→검수하기→다시 이용하기다.

Corporate PR을 첫 참조 상품으로 하되, 업무 범용성과 단일 호출형·다단계형의 차이를 설명한다. 마켓플레이스가 없어도 제품 가치를 증명할 수 있는 독립 실행 시나리오를 포함한다.

## 구현 결정
제작자는 새 앱에서 템플릿을 고르고 자료·사례·검사 기준을 입력한다. 시험 결과를 확인한 뒤 릴리스를 발행한다. 고객은 입력 양식을 제출하고 부족한 자료를 보충한다. 검수자는 근거와 수정 차이를 확인해 승인 또는 재작업을 결정한다. 운영자는 실패·비용·대기 작업을 관리한다. 첫 출시의 완료 조건은 다른 사업 시스템 연결 없이 이 흐름을 한 번 완주하는 것이다.

## 계약 및 검증 연결
공통 객체는 06_CANONICAL_OBJECTS_AND_STATE_CONTRACTS.md, 인터페이스는 13_PUBLIC_API_EVENTS_AND_INTEROPERABILITY.md를 따른다. schemas/, examples/, tickets/, tests/의 동일 식별자를 사용한다. 상태 변경 시 revision을 검사하고 결과 버전을 보존한다.

## 완료 증거
담당자는 변경 파일 목록, 검사 결과 원문, 실패·미실행 항목과 복구 방법을 남긴다. 명세 작성 완료는 소프트웨어 구현 완료를 뜻하지 않는다.

## 갤러리 v2 개정 계약
방문자→체험자→제작자 또는 의뢰자 전환을 추가한다. 세 주요 목적은 내 노하우 서비스화, 같은 일의 결과 비교, 제작자에게 완성 의뢰다.
