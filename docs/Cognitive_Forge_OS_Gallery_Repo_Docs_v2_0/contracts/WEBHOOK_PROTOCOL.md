# Webhook 전달 계약

발신자는 UTF-8 본문 원문에 HMAC-SHA256을 적용한다. 서명 입력은 timestamp + "." + raw_body이며 헤더 X-Forge-Timestamp, X-Forge-Signature를 사용한다. 수신자는 등록된 연결 비밀값과 상수시간 비교를 사용하며 기본 5분 이내 요청만 수용한다. 재전송은 같은 event_id와 새 전송 시각·서명을 사용한다. 이는 이 제품의 제안 계약이다.

2xx는 수신 확인이다. 429와 5xx는 지수 백오프와 jitter로 최대 8회 재전송하고 Retry-After를 상한 내에서 반영한다. 다른 4xx는 운영자 확인 대상으로 보낸다. 24시간 전달 한도를 넘으면 실패 큐에 보관하고 수동 재전송을 허용한다. 발신자의 성공 응답이 외부 업무 완료를 뜻하지 않는다.

자료 원문과 서명 URL은 기본 이벤트에 넣지 않는다. 연결별 허용 앱·작업공간과 이벤트 목록을 검사한다. 수신자는 event_id를 중복 제거하고 실행 revision이 불명확하면 조회 API를 사용한다. callback은 등록·검증된 HTTPS 주소만 허용하며 리다이렉트와 사설망 목적지를 제한한다.
