# D23 제작자·권리·파생 관계

CreatorProfile의 표시 이름은 실명·활동명·브랜드명을 허용한다. 경력은 self_declared와 checked를 구분하며 확인 범위·일자·담당자를 저장한다. 특정 에이전트의 품질 등급으로 자동 전환하지 않는다. 제작·전문 기준 제공·검수·운영 기여를 별도 기록한다.

fork_policy는 prohibited, private_only, attribution_required 중 선택한다. 플랫폼 예시는 attribution_required이며 소유자의 고객 자료는 제외한다. 라이선스 버전과 적용 대상을 발행 시 고정한다. 일반 지식 기반 역할 템플릿에는 expert_verified=false를 유지한다. 원본의 평가·제작자 경력·승인은 파생 팩이 상속하지 않는다.

공개 사례는 소유자의 공개 권한을 확인한다. 신고 대상은 도용·사칭·민감자료·오해를 유발하는 능력 표시 등이며 운영자는 숨김→확인→수정·복구·보관을 처리한다. 원본 비공개 전환과 이미 허용된 파생물 권리는 해당 발행 당시 조건에 따라 검토한다. 무조건 연쇄 삭제하지 않는다.

계정 삭제 후 거래 증거 보존과 공개 프로필 제거는 구분한다. 고객 원문과 정산상 필요한 최소 기록은 각각 보존 정책을 적용한다. 법적 약관 문구는 출시 대상에 맞춘 별도 검토 대상이며 이 문서는 제품 동작 규격이다.
