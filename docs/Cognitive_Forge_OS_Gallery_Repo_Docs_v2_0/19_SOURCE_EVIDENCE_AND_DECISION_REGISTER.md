# D19 SOURCE_EVIDENCE_AND_DECISION_REGISTER

버전 2.0 · 2026-11-01 · 구현 지시 명세

## 목적과 범위
교재와 소스에서 가져온 사실, 설계 해석, 신규 제안을 구분한다. 모든 주요 결정에 근거, 대안, 선택 이유, 영향 범위와 재검토 조건을 붙인다.

1급 교재 원문이 확보되지 않은 상태를 명시하고, TASKFLOW→CogCL/QPE 전이 가이드를 1급 공식 교재로 호칭하지 않는다. 프레임워크·API·표준의 구체적 버전은 해당 문서 제작 시 공식 문서에서 재확인한다.

## 구현 결정
근거 자료는 기존 계획서의 교재·코드 경로를 승계한다. TASKFLOW 중급 교재의 형태·상태·경계와 전이 가이드의 작성 규격·실행 계약 분리를 적용했다. 1급 교재 원문은 미확보다. ADR01 독립 Forge 기능 우선, ADR02 공통 RunService, ADR03 불변 릴리스와 산출물, ADR04 선택 외부 어댑터, ADR05 내부 Zod 정본과 배포 JSON Schema 생성 방향을 채택한다. 이 패키지의 JSON Schema는 구현팀이 Zod에 이식·동등성 검증할 전달 규격이다.

## 계약 및 검증 연결
공통 객체는 06_CANONICAL_OBJECTS_AND_STATE_CONTRACTS.md, 인터페이스는 13_PUBLIC_API_EVENTS_AND_INTEROPERABILITY.md를 따른다. schemas/, examples/, tickets/, tests/의 동일 식별자를 사용한다. 상태 변경 시 revision을 검사하고 결과 버전을 보존한다.

## 완료 증거
담당자는 변경 파일 목록, 검사 결과 원문, 실패·미실행 항목과 복구 방법을 남긴다. 명세 작성 완료는 소프트웨어 구현 완료를 뜻하지 않는다.

## 갤러리 v2 개정 계약
이번 개정은 사용자 요청의 36종·갤러리·전문가 참여·프로젝트 매칭 기획에 근거한다. 새로운 시장 수요나 실제 성능을 입증한 것으로 제시하지 않는다.
