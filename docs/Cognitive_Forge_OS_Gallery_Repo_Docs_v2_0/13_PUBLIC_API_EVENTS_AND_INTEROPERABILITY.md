# D13 PUBLIC_API_EVENTS_AND_INTEROPERABILITY

버전 2.0 · 2026-11-01 · 구현 지시 명세

## 목적과 범위
외부 시스템이 에이전트를 찾고, 실행하고, 자료를 보완하고, 상태를 구독하고, 권한 있는 검수 결정을 제출하며, 산출물을 받는 계약을 정의한다. OpenAPI, 이벤트 스키마, 오류·재시도 규칙의 설명서 역할을 한다.

인증 주체·작업공간·소유권·승인 권한·멱등성·이벤트 순서·재전송·내보내기 정책을 포함한다. 특정 외부 프로젝트 이름이 핵심 도메인 객체나 실행 코드에 박히지 않게 한다.

## 구현 결정
외부 요청은 bearer 인증, 작업공간 범위와 허용 앱을 확인한다. POST /runs는 Idempotency-Key가 필수다. 동일 키·동일 요청은 기존 run을 반환하고 다른 본문은 409다. 추가 입력과 검수 결정은 expected_revision을 요구한다. 이벤트는 최소 한 번 전달되며 중복·순서 역전을 허용한다. event_id로 중복 제거 후 필요하면 run을 재조회한다. 서명 검증과 전송 시각 허용 범위를 적용하고 콜백 주소는 등록된 HTTPS 목적지만 허용한다. 외부 승인 실패 시 자동 승인하지 않는다.

## 계약 및 검증 연결
공통 객체는 06_CANONICAL_OBJECTS_AND_STATE_CONTRACTS.md, 인터페이스는 13_PUBLIC_API_EVENTS_AND_INTEROPERABILITY.md를 따른다. schemas/, examples/, tickets/, tests/의 동일 식별자를 사용한다. 상태 변경 시 revision을 검사하고 결과 버전을 보존한다.

## 완료 증거
담당자는 변경 파일 목록, 검사 결과 원문, 실패·미실행 항목과 복구 방법을 남긴다. 명세 작성 완료는 소프트웨어 구현 완료를 뜻하지 않는다.
