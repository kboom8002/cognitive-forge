# D11 NATIVE_REVIEW_AND_ARTIFACT_WORKSPACE

버전 2.0 · 2026-11-01 · 구현 지시 명세

## 목적과 범위
Forge 내부 검수함, 수정 요청, 차이 비교, 승인, 산출물 버전, 다운로드, 보관과 재사용을 정의한다. 승인에는 인증된 결정자, 대상 버전 또는 내용 해시, 적용 범위, 시각과 필요 시 만료 조건을 연결한다.

승인 후 내용이 바뀌면 필요한 검수를 다시 수행한다. 외부 Work OS 연결 여부와 무관하게 이 흐름이 작동해야 한다. 외부 승인 위임 시의 권한 범위와 책임은 D13과 일치시킨다.

## 구현 결정
검수 화면은 산출물 본문·근거·변경 차이·검사 결과를 제공한다. 승인 요청에는 artifact_id, version, content_hash를 고정한다. 인증된 검수자에게만 결정 권한을 부여한다. 수정 요청은 이유와 대상 항목을 남기고 새 결과 버전을 만든다. 승인 후 내용 변경은 새 버전의 검수 상태를 pending으로 되돌린다. 다운로드는 권한 확인 후 발급하며 공개 결과에 내부 프롬프트를 포함하지 않는다. 외부 검수 위임은 작업 생성 시 authority와 허용 행동을 기록한다.

## 계약 및 검증 연결
공통 객체는 06_CANONICAL_OBJECTS_AND_STATE_CONTRACTS.md, 인터페이스는 13_PUBLIC_API_EVENTS_AND_INTEROPERABILITY.md를 따른다. schemas/, examples/, tickets/, tests/의 동일 식별자를 사용한다. 상태 변경 시 revision을 검사하고 결과 버전을 보존한다.

## 완료 증거
담당자는 변경 파일 목록, 검사 결과 원문, 실패·미실행 항목과 복구 방법을 남긴다. 명세 작성 완료는 소프트웨어 구현 완료를 뜻하지 않는다.

## 갤러리 v2 개정 계약
공개 비교 결과는 고객의 공개 허용 범위와 artifact version을 확인한다. 검수 요청은 어떤 제작자가 어떤 범위에 책임지는지 표시한다.
