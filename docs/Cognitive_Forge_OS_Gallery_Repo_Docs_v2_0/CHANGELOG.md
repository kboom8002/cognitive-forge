# Gallery Edition v2.0 — 2026-11-01

기존 20편에 갤러리 책임·공통 실행·권리·비교·매칭 개정을 반영하고 D20~D27 8편을 추가했다. 36종 카탈로그와 종별 명세, 초기 12종 시험용 팩, 36개 과제 입력, 11종 갤러리 스키마, 6개 프로젝트 묶음, 8개 갤러리 API 경로, 6개 개발 티켓과 16개 인수 시나리오를 추가했다.

팩 정의와 예시의 계약 정합성을 검사했다. 실제 실행 품질·현장 사용성·DB·실서버·공식 API 규격 검증은 미실행이다. 실행 SQL·상용 프론트엔드·실제 제공자 구현은 포함하지 않는다. 프로젝트 소스는 변경하지 않았다.
