# D27 갤러리 인수·측정

tests/gallery_acceptance.json은 GT01~GT16 시나리오의 정본이다. 계약 fixture 검사와 실제 서버·화면·모델 검사는 별도다. 이 문서 세트의 작성은 구현 성공을 의미하지 않는다.

측정 분모는 유효 방문 세션, 체험 시작, 체험 완료, fork 시작, fork 저장, 시험 완료, 발행, 의뢰 접수, 제안 수락, 납품 인수로 나눈다. 내부 운영자·봇·중복 재시도는 별도로 집계한다. 고객 원문 없이 사건 ID와 버전·시각을 수집한다.

출시 차단 조건은 preview_only 실실행 노출, 타 고객 자료 유출, 원본 검증 배지의 무근거 상속, 무권한 검수, 멱등 요청의 중복 생성, 만료·변경 산출물 승인 적용이다. 실제 환경의 검증 증거가 없으면 출시 준비 완료로 표시하지 않는다.

사용성 시험은 전문가·비개발자·고객 역할로 수행한다. 샘플만 체험한 사용자와 자기 자료로 실행한 사용자를 구분한다. 제작 완료 시간을 측정하되 임의의 목표 달성을 실제 성과로 기록하지 않는다.
