# T01 계약과 상태

대상: packages/core

선행: 없음

## 작업
정의·앱·실행·산출물의 타입과 상태 전이 검사를 구현. 기존 공개 앱은 공통 서비스에 위임하고 고객 계약을 보존한다.

## 완료 기준
AT03의 상세 시나리오를 실행하고 원문 결과를 남긴다. 형식 검사 통과와 실제 모델 검증을 분리한다. 변경 범위의 타입·테스트·빌드를 확인한다.

## 실패와 복구
실패 시 신규 릴리스 적용을 중단하고 이전 릴리스 또는 기능 플래그로 복구한다. 데이터 삭제나 외부 작업의 취소를 자동 추정하지 않는다.

## 제출
변경 파일, 마이그레이션, 검사 원문, 남은 제약, 복구 확인을 제출한다. 현재 상태: NOT_IMPLEMENTED.
