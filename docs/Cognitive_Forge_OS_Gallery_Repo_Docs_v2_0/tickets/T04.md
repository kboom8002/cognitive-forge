# T04 평가와 릴리스

대상: packages/validation; packages/casepack

선행: T02

## 작업
형식·업무 검사, 평가 보고, 버전 고정과 발행 조건. 기존 공개 앱은 공통 서비스에 위임하고 고객 계약을 보존한다.

## 완료 기준
AT04,AT05,AT15의 상세 시나리오를 실행하고 원문 결과를 남긴다. 형식 검사 통과와 실제 모델 검증을 분리한다. 변경 범위의 타입·테스트·빌드를 확인한다.

## 실패와 복구
실패 시 신규 릴리스 적용을 중단하고 이전 릴리스 또는 기능 플래그로 복구한다. 데이터 삭제나 외부 작업의 취소를 자동 추정하지 않는다.

## 제출
