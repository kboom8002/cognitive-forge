# D20 갤러리 제품·탐색 명세

## 사용자 흐름
홈 /gallery에서 해결할 일과 결과물을 선택한다. 카드에는 제목·제작자·주요 입력·산출물·이용 가능 상태를 표시한다. /gallery/:slug에는 입력→결과 샘플, 사용 범위, 질문 조건, 검사 기준, 릴리스, 제작자 역할, 제공 서비스가 있다. 준비된 샘플은 저장된 예시라는 표시를 붙인다.

## 상태와 행동
preview_only는 예시 보기만 허용한다. test_ready는 소유자 시험만 허용한다. published_runnable은 서버가 실제 릴리스와 capability·평가 gate를 확인한 경우에만 내 자료로 실행을 허용한다. paused와 archived는 신규 실행을 차단하되 기존 작업 이력은 보존한다. 공개 목록 상태는 실제 실행 준비 상태와 별도로 관리한다.

## 탐색과 노출
주된 산출물 카테고리는 하나만 선택한다. 업종·언어·자료 형식·검수 포함 여부를 추가 필터로 둔다. 검색 결과는 먼저 수행 가능 조건을 검사하고 관련 과제와 사례를 보여준다. 스폰서 노출은 표시하며 평가 점수와 혼합하지 않는다. 신규 제작자에게 별도 탐색 슬롯을 제공한다.

## 화면 동작
복제 버튼은 권리 정책을 확인한 뒤 로그인과 작업공간을 선택한다. 비공개 고객 입력을 예시로 자동 게시하지 않는다. 비교는 같은 평가 가능한 결과 유형을 가진 최대 3개 후보를 선택한다. 조건이 맞지 않으면 이유를 표시하고 비교를 시작하지 않는다. 키보드 초점·스크린리더 상태·명확한 오류 복귀 경로를 제공한다.

## 측정
view_listing, demo_open, demo_run, fork_started, fork_saved, test_completed, listing_published, brief_submitted, delivery_accepted를 별도 이벤트로 기록한다. 본문과 고객 원문은 분석 이벤트에 넣지 않는다. 방문→체험과 체험→의뢰는 분모와 기간을 명시해 계산한다.
