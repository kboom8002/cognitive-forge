# D14 REFERENCE_AGENTS_AND_INTEGRATION_RECIPES

버전 2.0 · 2026-11-01 · 구현 지시 명세

## 목적과 범위
첫 참조 구현은 Corporate PR 제작·검수 에이전트다. 두 번째는 단일 단계의 FAQ 또는 입력 정리 에이전트로 정해, 모든 서비스에 복잡한 체인이 필요하지 않음을 보여준다.

자료 접수부터 산출물 승인까지 일관된 예시 ID와 데이터를 사용한다. 외부 시스템을 흉내 내는 최소 클라이언트로 실행·조회·결정·이벤트 수신을 검증한다. TF-Studio·DualBrain·KHERE·AI홈피 연결은 이 표준 인터페이스의 적용 예시로 작성한다.

## 구현 결정
기업 PR 참조 팩은 자료 정리→충돌 확인→소개·FAQ 생성→수치·근거 검사→사람 검수의 흐름이다. 예시 기업 한빛공방은 합성 기업이며 실적을 임의 생성하지 않는다. 단일 FAQ 팩은 제공 정보만으로 질문에 답하고 자료가 없으면 waiting_input으로 전환한다. 외부 연동은 요청→조회→보완→검수→산출물 조회를 수행하는 최소 클라이언트로 먼저 검증한다. TF-Studio는 교육 과제를, DualBrain은 외부 업무를 연결하되 핵심 계약에 해당 프로젝트의 고유 필드를 넣지 않는다.

## 계약 및 검증 연결
공통 객체는 06_CANONICAL_OBJECTS_AND_STATE_CONTRACTS.md, 인터페이스는 13_PUBLIC_API_EVENTS_AND_INTEROPERABILITY.md를 따른다. schemas/, examples/, tickets/, tests/의 동일 식별자를 사용한다. 상태 변경 시 revision을 검사하고 결과 버전을 보존한다.

## 완료 증거
담당자는 변경 파일 목록, 검사 결과 원문, 실패·미실행 항목과 복구 방법을 남긴다. 명세 작성 완료는 소프트웨어 구현 완료를 뜻하지 않는다.
