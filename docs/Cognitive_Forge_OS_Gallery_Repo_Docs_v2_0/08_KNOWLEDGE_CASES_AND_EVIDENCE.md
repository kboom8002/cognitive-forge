# D08 KNOWLEDGE_CASES_AND_EVIDENCE

버전 2.0 · 2026-11-01 · 구현 지시 명세

## 목적과 범위
전문 지식, 긍정·실패 사례, 고객 입력, 확인된 사실, 미확인·상충 정보의 저장과 사용 규칙을 정의한다. 출처 위치, 자료 버전, 이용 권한, 갱신일, 고객 범위와 결과의 근거 연결을 포함한다.

자료 수집·검색은 최소 필요 기능부터 구현한다. Graph RAG나 지식그래프 전체 구축을 선행 조건으로 두지 않는다. 고객 실행이 끝났다는 이유로 해당 자료를 공용 지식이나 정답 사례에 자동 편입하지 않는다.

## 구현 결정
자료는 workspace_id, source_id, version, content_hash, title, locator, permission, collected_at을 갖는다. 결과의 claim은 source_id와 위치를 연결한다. 현재 고객 입력은 공용 참조 지식에 자동 편입하지 않는다. 상충 사실은 conflict로 표시하고 자료 보완 또는 사용 제외로 처리한다. 첫 구현은 문서 추출·메타데이터 필터·필요 구간 검색을 제공한다. 출처 URL의 존재와 주장을 실제로 뒷받침하는지는 별도 검사한다. 파일 크기·형식 제한은 업로드 설정과 UI에 동일하게 적용한다.

## 계약 및 검증 연결
공통 객체는 06_CANONICAL_OBJECTS_AND_STATE_CONTRACTS.md, 인터페이스는 13_PUBLIC_API_EVENTS_AND_INTEROPERABILITY.md를 따른다. schemas/, examples/, tickets/, tests/의 동일 식별자를 사용한다. 상태 변경 시 revision을 검사하고 결과 버전을 보존한다.

## 완료 증거
담당자는 변경 파일 목록, 검사 결과 원문, 실패·미실행 항목과 복구 방법을 남긴다. 명세 작성 완료는 소프트웨어 구현 완료를 뜻하지 않는다.

## 갤러리 v2 개정 계약
공개 샘플·제작자 소유 사례·고객 실행 자료를 분리한다. 비교 입력의 수신자 범위는 세션 생성 때 고정하고 비공개 자료의 공통 benchmark 편입을 금지한다.
